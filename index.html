Auto-apply rolled effects
When on, rolling an effect immediately performs it (Reroll a slot, Swap two Pokémon, etc). When off — the default — rolling just announces which effect came up, and it's on you to apply it. This exists because custom effects you add have no built-in behavior for the app to run.
BST Max
Set a Base Stat Total ceiling. Pokémon above this total won't be generated for anyone.
Set Tera Types
Every newly generated Pokémon gets a random Tera Type (any of the 18 types, or Stellar) shown under its name. Pokémon already on a team keep showing their Tera Type once it's assigned, even if you turn this off later.
Mono Type Challenge
Each player gets a locked type shown next to their name (editable via dropdown). Generating for that player only pulls Pokémon that have that type. Leave a player's type blank and it's randomly filled in the moment you next generate for them. Works independently of Set Tera Types — both can be on at once.
